# 临空日历 Web 原型

这是一个手机优先的卡池排期 Web 原型，包含：

- 左右滑动切换月份，点击年月选择年份与月份
- 默认连续年览，可上下滚动查看完整 1、2 或 3 年排期
- 提供“紧凑”与“舒展”两种日历尺寸，并可通过 `?density=compact` 直接打开紧凑版
- 年历单日完整展示最多四条横杠，标准模式固定为 3px、紧凑模式固定为 2px
- 多人混池统一色、单人角色色、特别活动独立色
- 同一日期多个卡池、跨月卡池和常驻池
- 日期底部抽屉、卡池规则与原始微博公告入口
- 原始微博公告下方展示对应卡池图片，保留原始比例且不加强制外框；双人、三人、四人、五人图组使用固定网格布局
- 可从卡池详情上传本地游戏截图，拖动并缩放裁切画面，填写抽数、钻石和花费后实时预览并导出分享用 PNG 抽数卡片
- 免费四星、免费五星、密约、十日活动任务、签到和敖尹取消公告不显示抽数卡片入口
- 免费四星、免费五星与签到福利使用独立的右上角圆点标记
- 十日活动任务统一使用黄色圆点，右上角圆点每行两个并向右对齐换行
- 18 期常规「密约」使用 42% 半透明灰色横杠；2 期复刻使用同色圆点
- 每期「密约」的官方图片收进对应详情页，图组统一为一行一张；指定档期可按卡面精简展示
- 每期「密约」标题直接标出对应卡名，多张卡面使用斜杠分隔
- 「万鬼行绝」「肆雨照夜」「一幕一生」「如若午夜无眠」等指定卡池使用精简卡面图组
- 同日排期按多人混池、单人日卡、生日月池、单人月卡池、生日复刻、多人混池复刻、单人日复刻、单人月复刻、其他复刻、免费月卡、密约复刻、普通活动、普通密约的顺序展示
- 单人日卡池复刻统一显示 `[复刻]` 标题
- 主线分线更新作为独立筛选与福利圆点展示，同时归入“免费五星”，签到/任务可免费领取一张五星思念
- 筛选分为全部、混池、单人、四星签到、免费五星、分线更新、密约、特别；混池包含倾慕臻礼与星谕罗盘，生日复刻池归入单人池，特别包含其他签到与十日活动任务
- 收藏、分享、筛选与深浅色模式
- PWA 清单和离线缓存

## 本地查看

直接打开 `index.html` 即可查看页面。需要测试 PWA 安装和离线缓存时，在本目录启动任意静态服务器，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 当前演示数据

页面直接读取设备本地日期，并在首次打开、跨过午夜及从后台返回时自动定位到当前年月和今天。排期范围覆盖 2024–2026 年。数据来自用户提供的《恋与深空_微博全量整理_2026-10-30.xlsx》，目前展示 155 条主排期记录，并额外包含 4 条主线分线更新、补充活动与 20 期「密约」。

正式接入时，将 `window.TIDE_CALENDAR_DATA` 替换为接口请求结果即可。当前 `data.js` 已从带角色配色的 `恋与深空_微博全量整理_2026-10-30_角色配色.xlsx` 重新生成，卡池颜色直接读取该表“名称”列的填充色。

同格式的新排期表可以通过下面的命令重新生成 `data.js`：

```powershell
python .\import-schedule.py "C:\path\to\new-schedule.xlsx"
```

页面主视觉位于 `letter-theme.css`，颜色取自蓝紫、雾灰与灰粉参考色卡。该文件只控制界面主色；卡池自己的角色色和类型色仍来自内容数据。

## 数据字段

每个卡池建议保持以下结构：

```js
{
  id: "unique-event-id",
  title: "卡池名称",
  type: "mixed | solo | special | permanent",
  mode: "五人混池",
  start: "2025-08-12",
  end: "2025-08-31",
  color: "#55b8aa",
  subtitle: "副标题",
  tags: ["五人", "限定"],
  summary: "卡池速览",
  advice: ["安排建议一", "安排建议二"]
}
```

单人池的 `color` 应来自独立的角色颜色字段，不能从 Excel 单元格底色临时推断。常驻池使用 `permanent: true` 或 `end: null`。

## 三端同步方向

建议把正式版本的数据拆到统一内容接口，并发布 `contentVersion`。Web、iOS 和 Android 都读取同一份版本化数据，客户端在本地缓存最近一次成功结果。

日常排期和攻略更新只更新内容接口，不重新发布 App。iOS 和 Android 后续可使用 Capacitor 封装当前 Web 体验；需要锁屏实时活动、桌面小组件或系统级通知时，再开发原生界面并继续复用同一数据接口。
